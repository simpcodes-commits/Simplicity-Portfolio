# Simplicity Graphics Portfolio

A responsive portfolio website for Daniel Adeleye, a graphic designer specializing in bold visual identities, print, packaging, and digital design.

## Features

- Responsive layout with light and dark themes
- Theme-aware header and startup logos
- About section with a portrait and animated gradient frame
- Client logos with light and dark variants
- Portfolio, services, and contact sections
- WhatsApp contact button and email inquiry form

## Project structure

```text
.
├── Simplicity Graphics — Redesign.html  # Website source
├── Portrait.png
├── simm.png
├── brandslogo/                         # Client logos and theme variants
└── mylogo/                             # Site logo, favicon, and about portrait
```

## Running locally

Open `Simplicity Graphics — Redesign.html` in a browser. The site uses relative paths for its image assets, so keep the `brandslogo` and `mylogo` folders alongside the HTML file.
